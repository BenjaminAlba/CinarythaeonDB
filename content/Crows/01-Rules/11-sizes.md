# Sizes

> Source: Crows — Rules Booklet for Playtest 3, PDF page(s) 10.

Each creature and object in the game fits into a size category, which roughly describes their volume and weight. The Sizes table gives examples of creatures and objects of such sizes. Note that Tiny is the smallest size and Holy Shit is the largest, so these categories can contain creatures and objects that are infinitesimally little and big respectively.

**Sizes**

| Size | Example Creature | Example Object |
| --- | --- | --- |
| Tiny | Rat | Compass |
| Small | Lynx | Lute |
| Medium | Human | Heavy armor suit |
| Large | Grizzly bear | Cart |
| Huge | Elephant | Catapult |
| Holy Shit! | Blue whale | Barn |
