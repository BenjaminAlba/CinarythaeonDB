## Reading the stat blocks

Each creature has a statistics table, a characteristic table, an attack table, and separate ability headings. The creature lookup tables link directly to stat blocks. Outcome tables retain the printed tier numbers and effects.

| Notation | Reading |
| --- | --- |
| Bonus | The printed attack modifier; roll 2d10 plus this number. |
| 12–16 / 17+ | Printed Tier 2 / Tier 3 attack results. |
| dam / P dam | Damage / piercing damage. |
| RR | Resistance roll. |
| DT | Dungeon Turn. |
| tar | Targets. |
| (U) | Upside-down climbing. |
| X/Day or X/Rest | Retained usage limit as printed. |
| Asterisks | References to the marked abilities; original markers are retained even where inconsistent. |

This is a formatting pass on the supplied Markdown, not an errata pass. Statistics, attack modifiers, damage, ranges, equipment, and ability wording are preserved. In particular, some human names include a Power number that differs from the Power statistic; neither number has been changed. Incomplete wording and apparent source errors remain for Ref adjudication.

All 15 original filenames are retained for existing links. The “All booklets” and “Conversion notes” links above refer to the parent files from the earlier full conversion; those parent files were not in the supplied archive.
