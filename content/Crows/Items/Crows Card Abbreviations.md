# Crows Card Abbreviations

| Card notation       | Meaning                                                                         |
| ------------------- | ------------------------------------------------------------------------------- |
| A / M / S           | Agility / Mind / Strength                                                       |
| gc                  | Gold coins                                                                      |
| dam                 | Damage                                                                          |
| P dam               | Piercing damage                                                                 |
| AD                  | Armor Defense                                                                   |
| RR                  | Resistance roll                                                                 |
| DT                  | Dungeon Turn                                                                    |
| UD                  | Usage Dice; keep the printed recharge/exhaustion and roll timing in parentheses |
| R0–R5               | Spell rank                                                                      |
| Attk. / Act. / Man. | Attack / Action / Maneuver                                                      |
| Dur.                | Duration                                                                        |
| creat.              | Creature                                                                        |
| ≤11 / 12–16 / 17+   | Tier 1 / Tier 2 / Tier 3 results                                                |
| Stack               | Number of identical items that can share their listed inventory space           |
| Slots               | Space occupied by the item/stack; one unless the card specifies otherwise       |
| MW                  | Masterwork                                                                      |
